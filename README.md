# PANEL DE CONTROL DE ACCESOS PARA UN DEPARTAMENTO

### Para este proyecto, nos toco realizar un panel para los residentes de un departamento

El administrador principal manejara todo el panel sin restricciones, pero tambien habra ciertos roles:

* Administrador
* Visitantes
* Residentes

Las caracteristicas de los roles y sus funciones dentro del sistema:

### Administrador
* Gestión global de departamentos (altas, bajas y modificaciones).
* Asignación y administración de cuentas de residentes y personal de vigilancia.
* Supervisión y auditoría de la bitácora general de accesos históricos y en tiempo real.
* Configuración de parámetros de seguridad del edificio.

### Residente
* Perfil personal vinculado a un departamento específico.
* Generación de pases temporales e invitaciones digitales para visitantes.
* Consulta del historial de accesos registrados a nombre de sus visitas.
* Notificaciones de llegada de invitados.


# Funcionalidades

1. Control de acceso y sesiones segun rol de usuario.

2. Generacion de pases digitales por residente con fecha y nombre.

3. Modulo de validacion en tiempo real para personal de caseta.

4. Bitacora de accesos con opciones de busqueda

5. Panel administrativo para control de residentes y departamentos.
